# Jogo de Xadrez em Java

Projeto academico para demonstrar tres padroes GoF:

- **Builder**: construcao do tabuleiro inicial;
- **Facade**: interface simplificada para operar a partida;
- **Strategy**: regras de movimento das pecas.

## Executar

Na raiz do projeto, execute:

```bash
cd src
javac xadrez/*.java
java xadrez.Main
```

O programa inicializa o tabuleiro e simula uma sequencia de jogadas.
